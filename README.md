# GSGD 10-minute summary

This Overleaf/Beamer deck summarizes three points:

1. How current GSGD metadata coverage compares with GSIM.
2. How river, review-required, and non-river records are distinguished.
3. What is currently included in the gauge-level time-series product.

Compile `main.tex` with Overleaf's default pdfLaTeX engine.

## Data snapshot

- GSGD metadata: 60,538 records across 159 countries and regions.
- GSIM comparison total: 30,959 gauges.
- Difference: +29,579 records.
- GSGD time-series inventory: 51,633 files across 33 countries.
- Station status: 28,074 confirmed river, 31,559 probable river,
  380 review required, and 525 non-river.
- Of the 525 non-river records, 521 have matched time-series files and four AFD
  canal records remain metadata-only.

The deck uses the working-release statistics current on 14 October 2026.
